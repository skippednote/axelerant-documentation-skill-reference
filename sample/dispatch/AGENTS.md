## Hard rules

- Never change delivery semantics without an ADR. At-least-once is a contract with every consumer; see `docs/adr/0002-at-least-once-delivery.md`.
- Never write to `notifications.status` outside the dispatcher. The API is read-only on that column.
- Never add a provider SDK to `internal/api`. Providers belong in `internal/providers` behind the `Provider` interface.
- Migrations are append-only. Fix a bad migration with a new one.
- Do not edit `docs/reference/api.md` by hand. It is generated by `make openapi`.

## Conventions that differ from the defaults

- Config is read once at startup into `internal/config.Config`. There is no package-level `os.Getenv` anywhere else.
- Errors crossing a package boundary are wrapped with `fmt.Errorf("%w")`. Sentinel errors live in `internal/errs`.
- Times are stored and compared in UTC. The database column type is `timestamptz`.

## Pitfalls

- `make test-integration` silently passes zero tests if the compose stack is down. Check the test count.
- LocalStack does not enforce SQS visibility timeout the way AWS does, so a double-delivery bug will not reproduce locally. Reproduce it in staging.
- The `dispatch-outbound` queue has a 5-minute visibility timeout. A handler that runs longer causes a redelivery, not a failure.
