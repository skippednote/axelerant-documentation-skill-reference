# Set up a new repository

Confirm the product boundary, owner, tier, visibility and on-call responsibility. Add repository metadata and ownership before writing pages. Establish a runnable minimum and test it before adding execution dates.

Use the tier's required structure. Fixed Platform folders contain indexes and grounded pages, not plans or promises. A new system without enough evidence is unfinished, not compliant through filler.

Create AGENTS.md guardrails and CLAUDE.md's import. Add CI in blocking mode and report missing evidence instead of masking it with an ignore rule.
